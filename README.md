# gmailsyncal

Public home page and privacy policy for **gmailsyncal** — the Google Calendar sync of an internal office application.

- Home page: https://xxraynz.github.io/gmailsyncal/
- Privacy policy: https://xxraynz.github.io/gmailsyncal/#privacy

## What it does

Users who connect their Google account get their office appointments added to their own Google Calendar.
The sync is one-way (office application → Google Calendar) and uses only the `calendar.events` permission.

The application itself runs only inside the office network; this repository contains just the public page
required for the Google OAuth consent screen. No application code or data is stored here.
